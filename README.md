# Basics from scratch

2026 is the year LLMs made humans writing code pretty much obsolete. Software engineering is still relevant, but we're more like supervisors to claude than the actual engineers. A good supervisor, however, also understands the details, and thus should be able to write code from scratch, which I've had little training during the last 8 months or so.

I've written code for 20 years now (first 10 years as a hobby + last 10 years professionally), and I've seen that my coding ability has detoriated during the last ~8 months due to vibe coding. Thus I've decided to 1) do some practice, 2) better understand some concepts in the field I'm working in, and implement some basic AI algorithms from scratch. Everything you see in this repo is 100% human written, from mermaid diagrams to pytest tests.
